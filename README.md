# Krithi

Krithi is a beautiful, modern, and feature-rich local music player built natively for Android using Jetpack Compose and modern Android architecture.

## 🎵 Features
*   **Modern UI**: Fully built with Jetpack Compose featuring a sleek, responsive design and micro-animations.
*   **Theme Engine**: Customizable themes, including a signature Emerald Green aesthetic, with support for Day/Night modes.
*   **Audio Playback**: Powerful and stable audio playback service.
*   **Lyrics Parsing**: Built-in support for displaying and parsing lyrics seamlessly.
*   **Library Management**: Easily manage your local music, albums, artists, and playlists.
*   **Widgets**: Beautiful home screen widgets for quick controls.

## 🛠 Tech Stack
*   **100% Kotlin**: Written entirely in Kotlin.
*   **Jetpack Compose**: For a declarative and dynamic User Interface.
*   **Media3 / ExoPlayer**: Robust media playback engine.
*   **Coroutines & Flow**: For asynchronous operations and reactive programming.
*   **Room**: Local database for managing playlists and caching.
*   **Hilt**: Dependency Injection.

## 🚀 Getting Started
To build the app locally:
1. Clone this repository.
2. Open the project in the latest version of **Android Studio**.
3. Sync the Gradle project.
4. Run the app on your emulator or physical device.
